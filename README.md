One razor-sharp line, 200 characters or fewer, that gets you out of a pointless meeting — an entry for the [make.fun bounty "The Funniest Excuse for Skipping a Meeting"](https://make.fun/bounty/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163). An AI judge pairs excuses head to head and crowns the biggest laugh.

> Sorry, I can't make the meeting — my calendar and I are in a toxic relationship, and today it double-booked me with my own sanity.

## How it works

`main.py` holds the entry text as a constant, checks it against the competition gate (1–200 characters, a single line, not only white space), then writes it to `/output/entry.txt` with no trailing newline and prints it. The program is deterministic: it always writes the same text.

## Run it

```sh
python3 main.py
```
